# Видеодемонстрация

[Sayline-demo.mp4](Sayline-demo.mp4) — импорт, реальная локальная обработка, результат с возвращающимся голосом и JSON-экспорт. Это экран Android 15 x86_64; авиарежим включён, Wi-Fi выключен. Приложение не имеет разрешения INTERNET.

Для краткости видео смонтировано: первая часть ускорена в 4 раза, просмотр и экспорт — в 2 раза; эти подписи есть в кадре. Пауза между записью обработки и записью результата удалена. Обе части относятся к одному выполненному импорту, результат — example-transcript.json. Видеоролик не используется как замер скорости.

Исходники без ускорения: [обработка](inference-raw.mp4), [результат и экспорт](result-export-raw.mp4). Использован лицензированный составной пример FLEURS с возвращающимся голосом, а не естественная беседа. Лицензия и происхождение — [QA_AUDIO_LICENSES.md](../../src/mobile/app/src/androidTest/assets/QA_AUDIO_LICENSES.md).

Замеры полного конвейера на физическом телефоне и границы проверки — [результаты тестов](../../docs/TEST_RESULTS.md).
