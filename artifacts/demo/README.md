# Видеодемонстрация

[Демонстрация.mp4](Демонстрация.mp4) — импорт, реальная локальная обработка, результат с возвращающимся голосом и JSON-экспорт. Это экран Android 15 x86_64; авиарежим включён, Wi-Fi выключен. Приложение не имеет разрешения INTERNET.

Для краткости видео смонтировано: первая часть ускорена в 4 раза, просмотр и экспорт — в 2 раза; эти подписи есть в кадре. Пауза между записью обработки и записью результата удалена. Обе части относятся к одному выполненному импорту, результат — Пример.json. Видеоролик не используется как замер скорости.

Исходники без ускорения: [обработка](Обработка.mp4), [результат и экспорт](Результат_и_экспорт.mp4). Использован лицензированный составной пример FLEURS с возвращающимся голосом, а не естественная беседа. Лицензия и происхождение — [QA_AUDIO_LICENSES.md](../../src/mobile/app/src/androidTest/assets/QA_AUDIO_LICENSES.md).

Замеры полного конвейера на физическом телефоне и границы проверки — [результаты тестов](../../docs/Тестирование.md).
