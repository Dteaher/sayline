# Установка и использование

1. Скачайте `Sayline.apk` из Releases или `artifacts/apk` после `git lfs pull`.
2. Откройте APK на Android 8.0+ ARM64/x86_64 и разрешите установку из выбранного источника. Сборка подписана отладочным ключом для проверки решения.
3. Откройте Sayline. Нажмите «Импортировать аудио» и выберите локальный WAV, M4A или MP3. Максимум 20 минут и 512 МБ; поддержка сжатых форматов зависит от кодеков устройства.
4. Дождитесь этапов подготовки, определения говорящих и распознавания. Можно свернуть приложение или выключить экран. Отмена применяется после текущего нативного вызова.
5. В стенограмме доступны реплики, участники, временные отметки и воспроизведение. Имена участников и текст можно исправить.
6. Нажмите JSON и выберите место сохранения в системном окне. Кнопка «Поделиться» позволяет передать текст выбранному вами приложению.
7. Для записи разговора нажмите соответствующую кнопку. Разрешение микрофона запрашивается только при записи. Запись можно приостановить и продолжить.

Аудио и история находятся в закрытом хранилище приложения. Обновление поверх предыдущей версии сохраняет записи; удаление приложения удаляет его локальные данные. У приложения отсутствует разрешение INTERNET.

Формат экспорта:

```json
{"transcript":[{"speaker_id":"speaker_1","start_ms":1250,"end_ms":4380,"text":"Добрый день!"}]}
```

Нумерация участников действует внутри записи. Интервалы разных говорящих могут пересекаться. Это не означает, что распознаны слова обоих голосов при перебивании.
