# Форматы и протокол обработки

Сетевой акустический протокол к этому кейсу не применяется. Ввод — локальное аудио, рабочий формат — mono float32 16 кГц, вывод — JSON UTF-8 с массивом transcript.

`start_ms` и `end_ms` — целые миллисекунды; `speaker_id` стабилен для возвращающегося участника в одной записи. Временные границы получены из моделей. Перекрывающиеся реплики могут иметь общие интервалы. Отображаемое имя не заменяет идентификатор.

Повреждённый или слишком длинный файл завершается явной ошибкой. Прерванная запись метаданных восстанавливается из атомарного файла. Отмена проверяется до и после нативных этапов; текущий JNI-вызов не прерывается небезопасным уничтожением ресурсов.
