# Область применения и ограничения

| Параметр | Поддерживаемый режим |
|---|---|
| Платформа | Android 8.0+, ARM64 и x86_64 |
| Входные данные | WAV, M4A, MP3; сжатые форматы используют кодеки устройства |
| Размер записи | До 20 минут и 512 МБ |
| Обработка | Полностью на устройстве; модели включены в APK |
| Идентификаторы участников | Согласованы в пределах одной записи |
| Перебивания | Поддерживаются пересекающиеся интервалы; разделение аудиоисточников не выполняется |
| Отмена | После завершения текущего нативного этапа |
| Поставка | APK с отладочной подписью для установки и проверки |

## Условия распознавания

Число групп и назначение реплик определяются моделями. На результат влияют длительность реплик, сходство голосов, шум и расстояние до микрофона; возможны разделение одного голоса на несколько групп и объединение разных голосов. Стенограмма и имена участников доступны для ручного редактирования.

## Область измерений

Время обработки измерено на телефоне 2311DRK48G. Диаризация оценена на AMI; русские функциональные проверки выполнены на фиксированных примерах. Для двух исследованных естественных русских звонков получены 16 и 7 групп; ручной эталон DER/WER для них не подготовлен. Протоколы и состав выборок приведены в [результатах тестов](Тестирование.md).

Нагрузочный сценарий длительностью 20 минут выполнен на x86_64 с повторяющейся синтетической речью. Скорость на других устройствах зависит от оборудования и записи. Публикация в магазине приложений находится за рамками этой поставки.
