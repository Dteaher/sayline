## Ускорение на телефоне

Устройство 2311DRK48G, ARM64. Порядок сравнения потоков: 2 → 4 → 4 → 2. Измерялся полный проход с загрузкой моделей; декодирование файла выполнено до сравнений.

| Пример | Два потока, среднее | Четыре потока, среднее | Сокращение времени |
|---|---:|---:|---:|
| Возвращающийся голос, 39,32 с | 26,170 с | 21,662 с | 17,23% |
| Два актёрских голоса | 34,455 с | 31,583 с | 8,34% |

Все четыре экспорта каждого примера совпали целиком: слова, интервалы, ID участников. Оба Android-сравнения PASS. Для ARM64 включено до четырёх потоков; x86_64 сохраняет два. Область замера: восемь запусков на указанном телефоне.

Полный итоговый конвейер с импортом, хранением и экспортом отдельно проверен на составном русском примере FLEURS длиной 39,32 с. Время и стенограмма — final-pipeline-runtime.json и final-pipeline-transcript.json. Проверены возвращение первого участника и два разных голоса. Тип материала: составная читаемая речь.

Дополнительно пропускается извлечение ERes2Net при отсутствии двух пригодных опор: алгоритм уточнения в этом случае не может изменить результат. Ветка покрыта целевым Android-тестом; отдельный замер среднего ускорения этой ветки не проводился.

## Диаризация

Шесть диагностических AMI-фрагментов: DER 23,48% → 22,81%. Три заранее отделённых новых фрагмента: DER 26,15% → 25,57%, JER 44,90% → 44,60%, MAE числа участников 2,67 → 2,33. Состав отложенной выборки: три англоязычных фрагмента; изменение метрик получено на одном из них. DER включает перекрытия, collar=0; пропуски, ложная речь и путаница представлены отдельно. Подробный протокол — src/mobile/NATIVE_EVIDENCE_RESULTS.md.

Дополнительная исследовательская выборка: два естественных русских звонка, 16 и 7 полученных групп. Ручная разметка DER/WER для этих записей не подготовлена. Четыре фиксированных русских примера прошли Android-регрессию слов и участников. В поставке используются настройки, выбранные по результатам сравнений; экспериментальные варианты выключены.

## Нагрузка и границы проверки

Нативный конвейер 0.7 обработал на x86_64 20 минут повторяющейся синтетической речи в фоне с выключенным экраном: 334139 мс, последняя граница 1199,9785 с. Служба и wake lock после завершения освобождены. Тест выполнялся до финального изменения числа потоков ARM64 и оформления. Область этого сценария: синтетическая нагрузка на эмуляторе.

Для финальной сборки выполнены целевые Android-проверки изменённых участков и физического телефона. Полный повторный Android-набор и статистическая оценка на размеченных естественных русских беседах — NOT RUN. Исторические проверки представлены отдельно в исходных отчётах.

## Воспроизведение

Из src/mobile: `./gradlew :app:testDebugUnitTest :app:lintDebug :app:assembleDebug :app:assembleDebugAndroidTest`; `python -m unittest discover -s tests -p 'test_*.py'`. На Windows сначала `. ./scripts/env.ps1`. После scripts/build.ps1: `python scripts/verify-artifacts.py`.

Сравнение потоков: `adb -s DEVICE shell am instrument -w -r -e class ru.neuroscribe.PhonePerformanceTest -e phone_benchmark true ru.neuroscribe.test/androidx.test.runner.AndroidJUnitRunner`. Для второго примера добавить `-e benchmark_asset actors-female.wav`.
