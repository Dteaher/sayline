# Диаризация 0.5 — чистые образцы, 8 ноября 2026

Уточнение использует свободные от других nativeID части реплик, сохраняя прежние надёжные опоры. Это ограниченное улучшение: на новой отложенной выборке выигрыш не получен. Лишние кластеры и текст одновременных голосов остаются нерешёнными.

## Что включено

Сначала выбираются те же исходные опоры, что в 0.4. Из оставшихся реплик вычитаются пересечения с другими nativeID; дополнительный эмбеддинг берётся из одного непрерывного чистого участка ≥0,2 с. Склейки разрозненных слогов нет. Новые образцы не вытесняют старые: общий предел — 256 образцов / 600 с входа эмбеддера, до 10 с на образец.

При наличии надёжных опор дополнительная реплика присоединяется только при среднем cosine-distance ≤0,4 и отрыве от второго кандидата ≥0,1. Надёжные группы повторно не кластеризуются. Неуверенный или непохожий редкий голос сохраняет прежнее назначение; короткая длительность сама по себе не основание для слияния. Когда исходных опор недостаточно, используется чистый образец с учётом его фактической длительности. Обновление не восстанавливает речь, уже потерянную сегментацией.

Новые веса не добавлены. Сохранены sherpa-onnx 1.13.8, native threshold 0,5, ERes2Net refinement 0,6, minDurationOn 0,15 с, minDurationOff 0,4 с, группировка с паузой 1,2 с. Времена исходных интервалов сохраняются; ASR работает на сгруппированных интервалах.

## Измерения

AMI: 180-секундные фрагменты английских встреч, ручная ортографическая разметка с автоматически выровненными временами слов (`only_words`). DER без допуска границ, с перекрытиями; JER по минимальному Jaccard-cost. Это host-инференс, не Android-скорость и не естественная русская беседа.

| Показатель | 9 development: 0.4 → 0.5 | 3 новых holdout: 0.4 → 0.5 |
|---|---|---|
| DER | 19,95% → 18,19% | 24,10% → 24,10% |
| JER | 39,36% → 37,46% | 43,70% → 43,70% |
| Средняя абсолютная ошибка числа участников | 4,11 → 3,89 | 5,67 → 5,67 |
| Правильный голос, интервалы ≤0,5 с | 12/62 → 13/62 | 8/22 → 8/22 |
| Правильный голос, интервалы ≤1 с | 17/89 → 20/89 | 11/31 → 11/31 |

На development нет ухудшения DER/JER отдельных файлов; однако общие пропуски выросли с 72,60 до 73,37 speaker-seconds, ложная речь — с 50,39 до 51,47. Снижение общей ошибки обеспечено уменьшением путаницы. Пропуски внутри перекрытий также слегка выросли. Это не улучшение всех компонентов.

Свежий holdout: IS1008a, ES2011a, TS3004a из опубликованной AMI dev-части; участники не пересекаются с нашим development. Конфигурация зафиксирована до измерения. На всех трёх файлах результаты совпали с прежними. Обобщаемый выигрыш и максимальные баллы **не доказаны**. Состав/хеши — `tests/audio/cleanrefs-confirmation-20261108/manifest.json`, политика и сырые результаты — `tests/evidence/cleanrefs-confirmation-20261108/`.

Android 15 x86_64: четыре фиксированных русских примера сохранили слова и число голосов. Ещё 12 заранее выбранных записей FLEURS ru validation, строки 20–31: WER 5/234 = 2,14% у обоих вариантов. Это чтение, без ручной проверки опубликованного эталона и без разметки говорящих. Две строки имеют общий текст, ещё одна повторяет текст ранее проверенного предложения; записи новые, полной текстовой независимости нет. Нормализация: Unicode-слова, регистр, ё→е, без числовых подстановок.

Для 124,14 с этих записей измерено 27,141 → 27,668 с обработки (RTF 0,219 → 0,223). Один последовательный baseline/candidate запуск, PCM уже декодирован; включены загрузка моделей, диаризация и ASR. Это не доказательство ускорения. PSS — снимок после обработки, не пиковая память.

## Что отвергнуто

- Полная повторная кластеризация чистых образцов с native threshold 0,7 улучшала среднее, но резко ухудшила IS1009a: DER 22,82% → 39,38%. В приложение не включена. Первая неудачная validation (IS1009a, TS3003a, EN2002a) после этого явно стала development, а не повторным независимым тестом.
- Уменьшение паузы группировки до 0,4 с изменило правильное «Хонсю» на «Хонтю» в русском регрессионном примере. Оставлено 1,2 с.
- ResNet34, ERes2Net и их совместные признаки сравнены на development. Второй дополнительный extractor не дал преимущества выбранному варианту и не включён.

## Проверка воспроизводимости

Research и Android используют одну функцию выбора опор и одинаковое округление времён до PCM samples. Исправлены переиспользование Gradle-результата между фазами и кеш эмбеддингов: ключ включает аудио, модель, точные окна и версию extractor; проверяется хеш файла векторов. Scorer отклоняет неполную отложенную выборку. Development и новый holdout пересчитаны после исправления общего бюджета; настройки по итоговому holdout не менялись.

Для воспроизведения: `prepare-diarization-corpus.py --cleanrefs-confirmation`, затем `cleanrefs-experiment.py probe --confirmation --split development`; Kotlin `CleanReferenceEvaluation` с `-PdiarizationResearch=true` выполняет фазы `windows` и `refine`, между ними — `cleanrefs-experiment.py embed --confirmation --split development`, после — `score`. Переменные: `NEUROSCRIBE_CLEANREFS_EVAL` (папка кеша), `NEUROSCRIBE_CLEANREFS_SPLIT`, `NEUROSCRIBE_CLEANREFS_PHASE`, `NEUROSCRIBE_CLEANREFS_CONFIRMATION=true`. Отложенные результаты уже раскрыты и не могут снова служить неизвестной проверкой новой настройки.

Физический ARM64, естественный русский DER, независимое распознавание текста всех перебивающих голосов — NOT RUN / NOT IMPLEMENTED. По указанию пользователя дальнейшие проверки проведены только на эмуляторе; отклонённая телефоном установка тестового пакета не считается успешной проверкой.
